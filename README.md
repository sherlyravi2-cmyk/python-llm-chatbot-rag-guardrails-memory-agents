# Python-Based Intelligent LLM Chatbot with RAG, Guardrails and Memory Agents

## Project Overview
This project demonstrates the integration of Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), Guardrails, and Memory Agents to build an intelligent chatbot capable of generating accurate, context-aware, and safe responses.

## Objectives
- Develop an intelligent AI chatbot.
- Implement Retrieval-Augmented Generation (RAG).
- Maintain conversational memory for context retention.
- Ensure safe and reliable responses using guardrails.
- Evaluate chatbot performance.

## Features
- Context-aware responses
- Retrieval-Augmented Generation (RAG)
- Safety guardrails
- Conversational memory
- Response evaluation

## Technologies Used
- Python
- Generative AI
- Large Language Models (LLMs)
- Retrieval-Augmented Generation (RAG)
- GitHub Copilot

## System Architecture
User Query → Guardrails → Retrieval → Memory → Prompt → LLM → Response

## Project Workflow
1. User submits a query.
2. Guardrails validate the query.
3. Relevant information is retrieved using RAG.
4. Memory module maintains conversation history.
5. LLM generates a response.
6. Response is evaluated before delivery.
